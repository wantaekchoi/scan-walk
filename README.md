# scan-walk

3D Scanner App 같은 LiDAR 방 스캔(USDZ)을 브라우저에서 열어 1인칭으로 걸어 다니며 보는 뷰어다.
벽에 막히고, 낮은 턱은 넘어가고, 필요하면 비행으로 벽을 뚫고 다닌다.

## 개인정보

파일은 기기 밖으로 나가지 않는다. 브라우저 File API 로 읽어 그 자리에서 그린다. 서버에 올리는 코드도 없고, 계정도 없다.
마지막으로 연 파일은 다음에 바로 열리도록 이 브라우저의 IndexedDB 에만 저장된다(사이트 데이터를 지우면 사라진다).

## 쓰는 법

**아이폰**

1. 3D Scanner App 에서 스캔을 USDZ 로 내보내 "파일에 저장"한다.
2. Safari 로 이 페이지를 열고 `USDZ 열기` → `파일 선택` → 저장한 `.usdz` 를 고른다.
3. 왼쪽 엄지로 이동한다(멀리 밀수록 빠르다). 오른쪽을 드래그하면 시점이 돈다. 둘을 동시에 써도 된다.
4. 바닥을 두 번 탭하면 그 자리로 순간이동한다.

공유 버튼 → "홈 화면에 추가"를 하면 주소창 없이 전체 화면으로 열린다.

**PC**

파일을 창에 끌어다 놓는다. 화면을 클릭하면 마우스가 잠기고 마우스로 시점을 돌린다(Esc 로 풀림, 잠기지 않는 환경에선 드래그).
WASD·방향키로 이동하고, 더블클릭하면 그 바닥으로 순간이동한다. 비행 중엔 Space/E 로 위, Shift/Q 로 아래.

**버튼**

| 버튼 | 하는 일 |
|---|---|
| 열기 | 다른 파일 열기 |
| 걷기 / 비행 | 충돌·중력이 있는 걷기와 벽을 통과하는 비행을 바꾼다. 비행 중엔 ▲▼ 로 오르내린다 |
| 조명 | 스캔 텍스처엔 조명이 구워져 있어 기본은 조명 없이 그린다. 켜면 장면 조명을 받는다 |
| 축 | 방이 옆으로 누워 보이면 누를 때마다 위쪽 축을 바꾼다(+Y, +Z, −Z, +X, −X, −Y) |
| ×1 | 크기가 터무니없으면 배율을 바꾼다(×1, ×0.01, ×100, ×0.1, ×10) |
| 처음 | 시작 위치로 돌아간다 |

파일에 적힌 `upAxis`·`metersPerUnit` 는 자동으로 따른다. 축·배율 버튼은 그게 틀렸을 때 쓰는 손 보정이다.
눈높이는 1.6m, 넘을 수 있는 턱은 0.3m 까지다.

## 직접 띄우기

빌드가 없다. 아무 정적 서버로 띄우면 된다.

```sh
python3 -m http.server
```

`test/room.usdz` 는 시험용 합성 방(바닥·벽 4개·문틈·상자·0.18m 단)이다. `python test/make_room.py <폴더>` 가 만든 `room_y.usdz` 이고, Z-up·잘못 표기된 Z-up·cm 단위 변형도 같이 만든다(`pip install usd-core pillow`).

## 만든 것

- three.js r186 `USDLoader`(USDA·USDC·USDZ)로 읽는다.
- 충돌은 [three-mesh-bvh](https://github.com/gkjohnson/three-mesh-bvh) 의 characterMovement 예제 방식(캡슐 vs BVH)이다. 불러올 때 BVH 를 한 번 만든다.
- 라이브러리는 jsDelivr 에서 버전을 고정해 받는다(`index.html` 의 importmap).
