# scan-walk

3D Scanner App 같은 LiDAR 방 스캔(USDZ)을 브라우저에서 열어 1인칭으로 날아다니며 보는 뷰어다.
폰에선 왼쪽 엄지로 보는 방향을 따라 날고, 오른쪽 엄지로 시점을 돌린다. 걷기로 바꾸면 벽에 막히고 낮은 턱은 넘어간다.

## 개인정보

파일은 기기 밖으로 나가지 않는다. 브라우저 File API 로 읽어 그 자리에서 그린다. 서버에 올리는 코드도 없고, 계정도 없다.
페이지의 CSP(`connect-src 'none'`)가 fetch·XHR·WebSocket·beacon 을 막는다.
라이브러리는 importmap 의 SRI 해시로 고정해서, 이를 지원하는 브라우저에서는 CDN 파일이 바뀌면 앱이 뜨지 않는다.

마지막으로 연 파일은 다음에 바로 열리도록 이 브라우저의 IndexedDB 에만 저장된다.
지우려면 앱의 `잊기` 버튼을 누르거나, iPhone 설정 > Safari > 고급 > 웹사이트 데이터에서 이 사이트를 지운다.
다시 열다가 탭이 죽으면(메모리 부족) 다음 실행 때 자동으로 열지 않고 `다시 열기`/`잊기` 를 묻는다.
Safari 개인정보 보호 탭에서는 마지막 파일을 기억하지 못한다(WebKit 은 비공개 세션에서 IndexedDB 에 파일을 넣지 못한다). 앱은 그대로 쓸 수 있다.

## 쓰는 법

**아이폰**

1. 3D Scanner App 에서 스캔을 USDZ 로 내보내 "파일에 저장"한다.
2. Safari 로 이 페이지를 열고 `USDZ 열기` → `파일 선택` → 저장한 `.usdz` 를 고른다.
3. 바닥 위 눈높이에 떠서 시작한다. 한 손은 이동, 다른 손은 시점이다.
   - 왼쪽 엄지: 화면 왼쪽 절반에 대면 그 자리에 스틱이 생긴다. 앞뒤로 밀면 보는 방향으로 나아가고(위를 보면 올라가고 아래를 보면 내려간다, 바닥·천장·벽도 통과), 옆으로 밀면 수평으로 옆걸음한다. 놓으면 그 자리에 떠 있다.
   - 오른쪽 엄지: 화면 오른쪽 절반을 드래그하면 시점이 돌고 위아래로 기운다. 스틱과 동시에 써도 된다.
   - 스틱은 가운데 조금은 무시하고, 살짝 밀면 천천히, 끝까지 밀면 최고 속도(3m/s)다.
4. 바닥을 두 번 탭하면 그 자리로 순간이동한다. 날던 중이면 거기 눈높이에 떠 있다.
5. `비행` 버튼을 누르면 `걷기`가 된다. 같은 스틱으로 수평으로 걷고 벽에 막힌다. 바닥 아래에서 바꾸면 그 바닥 위에 선다. 다시 날려면 버튼을 누른다.

공유 버튼 → "홈 화면에 추가"를 하면 주소창 없이 전체 화면으로 열린다.

**PC**

파일을 창에 끌어다 놓는다. 화면을 클릭하면 마우스가 잠기고 마우스로 시점을 돌린다(Esc 로 풀림, 잠기지 않는 환경에선 드래그).
WASD·방향키로 이동한다(날 때는 보는 방향으로, 걸을 때는 수평으로). Space/E 로 오르고 Shift/Q 로 내려간다(걷는 중엔 Space/E 가 날아오르기). 더블클릭하면 그 바닥으로 순간이동한다.

**버튼**

| 버튼 | 하는 일 |
|---|---|
| 열기 | 다른 파일 열기 |
| 비행 / 걷기 | 벽·천장·바닥을 통과하는 비행과 충돌·중력이 있는 걷기를 바꾼다. PC 에선 걷다가 Space 를 누르면 저절로 비행이 된다 |
| 조명 | 스캔 텍스처엔 조명이 구워져 있어 기본은 조명 없이 그린다. 켜면 장면 조명을 받는다(3D Scanner App 처럼 텍스처를 발광색에 넣은 파일도 같다) |
| 축 | 방이 옆으로 누워 보이면 누를 때마다 위쪽 축을 바꾼다(+Y, +Z, −Z, +X, −X, −Y) |
| ×1 | 크기가 터무니없으면 배율을 바꾼다(×1, ×0.01, ×100, ×0.1, ×10) |
| 처음 | 시작 위치로 돌아간다(비행으로) |
| 잊기 | 기억해 둔 마지막 파일을 지운다(지금 보는 스캔은 그대로) |

파일에 적힌 `upAxis`·`metersPerUnit` 는 자동으로 따른다. 축·배율 버튼은 그게 틀렸을 때 쓰는 손 보정이다.
눈높이는 1.6m, 걷기로 넘을 수 있는 턱은 0.3m 까지다. 시작은 스캔 범위 중심 아래 바닥 위 눈높이다. 거기 구멍이 있으면(창밖까지 스캔돼 중심이 밀린 경우 포함) 중심에서 가까운 바닥을 찾고, 바닥이 아예 없으면 범위 중심에 눈을 두고 시작한다. 걷다가 구멍으로 떨어지면 마지막으로 서 있던 자리로 돌아온다.
가로·세로가 모두 2m 미만이거나 폭과 높이가 둘 다 2m 미만인 물체 스캔(미끄럼틀·자동차 등)은 비행으로, 물체 밖에서 그 중심 높이로 물체를 바라보며 시작한다(`처음` 도 그 자리).
텍스처는 4096px 로 줄여 올린다(iOS 메모리 한도).

## 직접 띄우기

빌드가 없다. 아무 정적 서버로 띄우면 된다.

```sh
python3 -m http.server
```

`test/room.usdz` 는 시험용 합성 방(바닥·벽 4개·문틈·상자·0.18m 단)이다. `python test/make_room.py <폴더>` 가 만든 `room_y.usdz` 이고, Z-up·잘못 표기된 Z-up·cm 단위·바닥 없음·8k 텍스처 변형, 3D Scanner App 식 내보내기(발광색 텍스처, 30° 돌아간 방, 중심 아래 바닥 구멍)와 0.6m 물체(`object.usdz`)도 같이 만든다(`pip install usd-core pillow`).
자동 검사: `python test/make_room.py /tmp/rooms` 후 서버를 8765 에 띄우고 `ASSETS=/tmp/rooms node test/e2e.mjs`(Playwright 필요, 다른 주소·브라우저는 `BASE_URL`·`CHROMIUM`, 설명은 파일 첫머리).

## 만든 것

- three.js r186 `USDLoader`(USDA·USDC·USDZ)로 읽는다.
- 충돌은 [three-mesh-bvh](https://github.com/gkjohnson/three-mesh-bvh) 의 characterMovement 예제 방식(캡슐 vs BVH)이다. 불러올 때 BVH 를 한 번 만든다.
- 라이브러리는 jsDelivr 에서 버전을 고정해 받는다(`index.html` 의 importmap).
